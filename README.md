# 💰 FinTech — Personal Financial Literacy & Budgeting System

FinTech is a Python and Flask-based web application designed to help users understand and manage their personal finances through simple, income-based budgeting.

## 🎯 Project Goal

The goal of FinTech is to make financial planning easier to understand by showing users how their income can be distributed across important financial categories and comparing planned amounts with actual spending.

## ✨ Features

* 💵 Enter monthly income and financial information
* 🧮 Automatically calculate suggested budget allocations
* 📊 Compare suggested spending with actual spending
* 📁 Save financial records using CSV files
* 🌐 Web-based interface powered by Flask
* 📋 Simple and user-friendly financial planning system

## 📌 Budgeting Model

The current budgeting model distributes **50% of income** across selected expense categories:

| Category           | Suggested Allocation |
| ------------------ | -------------------: |
| Essential Expenses |                  25% |
| Groceries          |                  10% |
| Desires            |                   5% |
| Education          |                  10% |
| **Total**          |              **50%** |

The remaining income can be allocated toward other financial goals such as savings and future planning.

## 🛠️ Technologies Used

* **Python** — Financial calculations and backend logic
* **Flask** — Web application framework
* **HTML/CSS** — User interface
* **CSV** — Financial record storage

## 🚀 How to Run

1. Install Python.
2. Install Flask:

```bash
pip install flask
```

3. Open the project folder.
4. Run the application:

```bash
python app.py
```

5. Open your browser and visit:

```text
http://127.0.0.1:5000
```
